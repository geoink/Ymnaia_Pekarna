Как устроен расчёт

Используется градиентный бустинг с абсолютной ошибкой из курсовой. Он обучается на вашем ассортименте. Признаки включают календарь и прошлые продажи. Первые 35 дней формируют историю признаков, последние 14 календарных дней используются для проверки.

В проверке каждый прогноз делается на один день с уже известными продажами предыдущих дней. Для расчёта следующего дня модель отдельно обучается на всей доступной истории. WAPE показывает долю суммарной абсолютной ошибки. MAE выражается в штуках на товар за день. При нулевых суммарных продажах WAPE не определён.

Короткая проверка даёт предварительную оценку качества. Погода, акции, остатки и ограничения печи в эту модель не входят. Отрицательные строки суммируются как корректировки, отрицательный дневной итог ограничивается нулём.
