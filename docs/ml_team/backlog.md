# Бэклог ML-команды

Это готовые постановки для будущего внедрения. Все задачи имеют статус **proposed**; реальные исполнители не назначены. Роли — предлагаемые владельцы работы. Текущий учебный прототип и ретроспективное исследование уже находятся в репозитории.

**P0** — блокирует соответствующий этап; **P1** — необходимая реализация этапа. Приоритет не отменяет зависимости. Внешний benchmark в ML-010 — дополнительная ветка, не обязательное условие запуска пилота при достаточных собственных данных.

Суммарная предварительная оценка: **50 человеко-дней** активной работы. Она не равна календарной длительности: роли работают параллельно, а сбор истории, 14 рабочих дней shadow-режима и пилот добавляют ожидание.

Оценки уточняются после ML-001—ML-005. Машинная версия: [tasks.json](tasks.json); таблица для импорта: [backlog.csv](backlog.csv); [план поставки](delivery_plan.md).

GitHub Issues создаются скриптом `scripts/github_tasks.py --repo OWNER/NAME --apply`. Без `--apply` доступен локальный просмотр. Импорт добавляет роли в описание, но не назначает пользователей и не рассылает сообщения от имени команды.
