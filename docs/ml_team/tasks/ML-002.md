# ML-002. Подтвердить права на данные и воспроизводимость источников

**Приоритет:** P0 · **Роль:** Data Engineer + владелец данных · **Поставка:** R1

**Оценка:** 1 человеко-дн. активной работы. Ожидание данных и наблюдение считаются отдельно.

**Статус:** proposed — постановка подготовлена; исполнитель и календарная дата ещё не назначены.

**Зависимости:** нет.

## Цель

Разрешить работу с данными и определить, какие материалы можно публиковать.

## Входы

Общая постановка: `docs/ml_team/brief.md`; результаты прототипа: `reports/results.md` и `reports/research/results.md`. Артефакты зависимых задач должны быть приняты до начала работ. Для задач внедрения нужны данные пилотной пекарни; открытый исторический набор их не заменяет.

## Работы

1. Зафиксировать владельца кассовой выгрузки и согласовать доступ к ней.
2. Составить реестр наборов, лицензий, версий, контрольных сумм и сроков хранения.
3. Исключить персональные данные покупателей из контура прогнозирования.

## Результат поставки

- `data_register.md`
- `access_and_retention.md`

## Критерии приёмки

- [ ] Есть подтверждение использования данных конкретной пекарни для пилота.
- [ ] Сырой Kaggle CSV и реальные чеки исключены из публичного репозитория.
- [ ] У всех источников есть ссылка, владелец и разрешённый способ распространения.

## Порядок сдачи

PR с артефактами и свидетельствами проверок; ревью владельца роли по плану поставки. Имена файлов выше — ожидаемые будущие результаты задачи, а не утверждение об их наличии. При отсутствии входов указать блокер и владельца; не заменять фактические данные вымышленными.
