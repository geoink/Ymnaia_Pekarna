# ML-017. Провести пилот и оценить эффект с неопределённостью

**Приоритет:** P0 · **Роль:** аналитик + управляющий + ML Lead · **Поставка:** R4

**Оценка:** 4 человеко-дн. активной работы. Ожидание данных и наблюдение считаются отдельно.

**Статус:** proposed — постановка подготовлена; исполнитель и календарная дата ещё не назначены.

**Зависимости:** ML-015, ML-016.

## Цель

Решить, стоит ли продолжать использование системы на основании фактического эффекта.

## Входы

Общая постановка: `docs/ml_team/brief.md`; результаты прототипа: `reports/results.md` и `reports/research/results.md`. Артефакты зависимых задач должны быть приняты до начала работ. Для задач внедрения нужны данные пилотной пекарни; открытый исторический набор их не заменяет.

## Работы

1. Запустить согласованное расписание методов и сохранять назначение, соблюдение и причины отклонений.
2. Рассчитать эффект по заранее заданному протоколу, интервалы и guardrails.
3. Проверить стоимость эксплуатации, чувствительность к пропускам и влияние ручных правок.

## Результат поставки

- `reports/pilot_effect.md`
- `reports/pilot_metrics.csv`
- `rollout_decision.md`

## Критерии приёмки

- [ ] Приведены абсолютный и относительный эффекты, доверительный интервал и число экспериментальных единиц.
- [ ] Основной анализ соответствует назначению метода; анализ соблюдения показан отдельно.
- [ ] При недостаточной мощности вывод обозначен как неопределённый, а не положительный.
- [ ] Зафиксировано решение rollout/iterate/stop с владельцем и обоснованием.

## Порядок сдачи

PR с артефактами и свидетельствами проверок; ревью владельца роли по плану поставки. Имена файлов выше — ожидаемые будущие результаты задачи, а не утверждение об их наличии. При отсутствии входов указать блокер и владельца; не заменять фактические данные вымышленными.
