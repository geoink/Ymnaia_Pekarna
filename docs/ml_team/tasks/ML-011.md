# ML-011. Построить допустимый план выпечки и сценарный расчёт

**Приоритет:** P1 · **Роль:** Data Scientist + управляющий · **Поставка:** R2

**Оценка:** 3 человеко-дн. активной работы. Ожидание данных и наблюдение считаются отдельно.

**Статус:** proposed — постановка подготовлена; исполнитель и календарная дата ещё не назначены.

**Зависимости:** ML-001, ML-009, ML-010.

## Цель

Преобразовать прогноз в выполнимую рекомендацию с учётом экономики и мощностей.

## Входы

Общая постановка: `docs/ml_team/brief.md`; результаты прототипа: `reports/results.md` и `reports/research/results.md`. Артефакты зависимых задач должны быть приняты до начала работ. Для задач внедрения нужны данные пилотной пекарни; открытый исторический набор их не заменяет.

## Работы

1. Учесть кратность партии, минимальный выпуск, остатки, вместимость печи и трудозатраты.
2. Сравнить квантильный план, текущий ручной план и простой baseline на одинаковых условиях.
3. Проверить чувствительность к затратам и ошибкам восстановления спроса; описать допущения.

## Результат поставки

- `src/planning/`
- `reports/planning_scenarios.csv`
- `planning_contract.md`

## Критерии приёмки

- [ ] Все рекомендации соблюдают согласованные ограничения или возвращают объяснимый статус infeasible.
- [ ] Ручные расчёты на малых примерах совпадают с результатом программы.
- [ ] При недоступной себестоимости или спросе результат явно помечен как сценарий.
- [ ] Сценарная экономия не выдается за измеренный эффект пилота.

## Порядок сдачи

PR с артефактами и свидетельствами проверок; ревью владельца роли по плану поставки. Имена файлов выше — ожидаемые будущие результаты задачи, а не утверждение об их наличии. При отсутствии входов указать блокер и владельца; не заменять фактические данные вымышленными.
