# ML-009. Оценить квантили для асимметричной цены ошибки

**Приоритет:** P1 · **Роль:** Data Scientist · **Поставка:** R2

**Оценка:** 3 человеко-дн. активной работы. Ожидание данных и наблюдение считаются отдельно.

**Статус:** proposed — постановка подготовлена; исполнитель и календарная дата ещё не назначены.

**Зависимости:** ML-001, ML-007, ML-008.

## Цель

Получить прогнозы, пригодные для выбора объёма при разной стоимости излишка и дефицита.

## Входы

Общая постановка: `docs/ml_team/brief.md`; результаты прототипа: `reports/results.md` и `reports/research/results.md`. Артефакты зависимых задач должны быть приняты до начала работ. Для задач внедрения нужны данные пилотной пекарни; открытый исторический набор их не заменяет.

## Работы

1. Обучить модели квантилей 0.1/0.3/0.5/0.7/0.9 на том же протоколе.
2. Оценить pinball loss, эмпирическое покрытие и ширину интервалов по периодам и SKU.
3. Проверить пересечение квантилей и правило коррекции; связать рабочую квантиль с затратами.

## Результат поставки

- `reports/quantile_calibration.csv`
- `quantile_policy.md`
- `configs/quantile_model.json`

## Критерии приёмки

- [ ] Указаны размер выборки и неопределённость оценки покрытия; заявлений о гарантированных 80% нет.
- [ ] Квантили неотрицательны и упорядочены после задокументированной коррекции.
- [ ] При отсутствии остатков прогноз назван квантилем продаж; переход к спросу требует ML-010.
- [ ] Формула tau = (p-c)/p применяется только при её явно перечисленных предположениях.

## Порядок сдачи

PR с артефактами и свидетельствами проверок; ревью владельца роли по плану поставки. Имена файлов выше — ожидаемые будущие результаты задачи, а не утверждение об их наличии. При отсутствии входов указать блокер и владельца; не заменять фактические данные вымышленными.
