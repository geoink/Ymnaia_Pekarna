# ML-010. Исследовать продажи, ограниченные наличием товара

**Приоритет:** P1 · **Роль:** Data Scientist + аналитик · **Поставка:** R2

**Оценка:** 4 человеко-дн. активной работы. Ожидание данных и наблюдение считаются отдельно.

**Статус:** proposed — постановка подготовлена; исполнитель и календарная дата ещё не назначены.

**Зависимости:** ML-005, ML-007.

## Цель

Оценить смещение от stockout и пригодность восстановления скрытого спроса.

## Входы

Общая постановка: `docs/ml_team/brief.md`; результаты прототипа: `reports/results.md` и `reports/research/results.md`. Артефакты зависимых задач должны быть приняты до начала работ. Для задач внедрения нужны данные пилотной пекарни; открытый исторический набор их не заменяет.

## Работы

1. Описать цензурирование, замену товаров и неполноту наблюдений; построить сегменты по наличию.
2. Сравнить обычное обучение, исключение явно цензурированных периодов и обоснованный метод восстановления.
3. При необходимости проверить метод на FreshRetailNet-50K как внешнем benchmark с иной областью применения.

## Результат поставки

- `reports/censoring_study.md`
- `stockout_data_card.md`
- `latent_demand_decision.md`

## Критерии приёмки

- [ ] Нет подмены неизвестного спроса наблюдаемыми продажами в проверке восстановления.
- [ ] Качество проверено на известных нецензурированных отрезках с искусственной маскировкой; ограничения описаны.
- [ ] Сравнение методов исключает утечку будущего наличия в признаки.
- [ ] Если данных недостаточно, явно принято решение отложить восстановление спроса.

## Порядок сдачи

PR с артефактами и свидетельствами проверок; ревью владельца роли по плану поставки. Имена файлов выше — ожидаемые будущие результаты задачи, а не утверждение об их наличии. При отсутствии входов указать блокер и владельца; не заменять фактические данные вымышленными.
