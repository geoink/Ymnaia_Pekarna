# Паспорт эксперимента

Краткая версия методики для проверки и защиты. Полное описание: [курсовая](coursework.md), [data card](data_card.md), [model card](model_card.md).

## Постановка

**Решение:** вечером оценить продажи восьми товаров на следующий календарный день, предполагая, что пекарня открыта. **Target:** `y[t, sku] = max(0, сумма Quantity за день и товар)`. **Тип задачи:** регрессия с временными признаками. Прогноз относится к нетто-продажам, а не к полностью наблюдаемому спросу.

**Источники:** [French Bakery Daily Sales](https://www.kaggle.com/datasets/matthieugimbert/french-bakery-daily-sales), Matthieu Gimbert. 234 005 строк, 600 дат с записями за 02.01.2021–30.09.2022. 37 дат полного календаря неизвестны. Восемь SKU заранее зафиксированы в `config.py`; редкие товары и услуги не моделируются.

**Признаки и смысл:** день недели отражает недельный ритм; месяц и годовые синус/косинус описывают календарь; SKU учитывает различие объёмов; лаги 1/7/14/28 дней и прошлые средние описывают текущий уровень; разброс и число известных дней показывают нестабильность и полноту истории. Текущая цель и будущие факты в признаки не входят.

## Исходный протокол

| Элемент | Фиксация |
|---|---|
| Прогрев признаков | Первые 35 календарных дней |
| Валидация | Июнь и июль 2022, расширяющаяся история |
| Кандидаты | lag7, mean4 weekday, HGB MAE, HGB Poisson, смесь HGB MAE и mean4 50/50 |
| Критерий выбора | WAPE по объединённым валидационным прогнозам |
| Выбранная модель | HGB MAE, validation WAPE 21,40% |
| Тест | 01.08.2022–30.09.2022, 59 наблюдавшихся дней × 8 SKU = 472 строки |
| Протокол прогноза | Один день вперёд; факты прошлых дней доступны; веса в тесте фиксированы |
| Параметры HGB | 250 итераций, learning_rate 0,06, 15 листьев, min_samples_leaf 20, L2 5, early_stopping false, seed 42 |

Итог: **WAPE 18,28%, MAE 12,23 шт.** У lag7 WAPE 28,07% и MAE 18,78 шт. Относительное снижение WAPE: `(28,07046 − 18,27978) / 28,07046 ≈ 34,88%`. Poisson получил WAPE 17,00%, но не заменяет выбранную по валидации модель. [Все исходные метрики](../reports/test_metrics.csv).

## Дополнительное исследование

Сентябрь 2021 — июль 2022, 11 месячных окон и 2 536 товаро-дней. Переобучение в начале каждого месяца, прогноз по-прежнему однодневный. Девять вариантов включают дополнительные простые правила и исключение групп признаков.

HGB MAE: **WAPE 28,08% против 35,18% у lag7**, преимущество в 10 из 11 окон. Macro MASE7 0,852, RMSSE7 0,811; сезонный масштаб берётся только из прошлого. Проверка неопределённости на исходном тесте использует парный bootstrap блоками 3/7/14 календарных дней. Все новые результаты являются **post-hoc исследованием**, поскольку исходный тест уже просмотрен. [Отчёт расширения](../reports/research/results.md).

## Экономические выводы

Сценарная потеря: `c × max(Q−D,0) + (p−c) × max(D−Q,0)`. Себестоимость c задана как 30/50/70% цены, продажи временно приняты за спрос D, остаточная стоимость и перенос остатков исключены. Множитель объёма выбран на валидации отдельно для метода и сценария.

При c/p = 0,5 условные потери HGB MAE составляют 3 377,65 евро против 5 195,98 евро у lag7 за исходный тестовый период. Это результат модели затрат, **не измеренная экономия пекарни**. Для измерения нужны выпуск, остатки, списания, реальная себестоимость и контролируемый пилот.

## Воспроизведение

```bash
python -m pip install -e '.[dev]'
bakery download
bakery run
bakery research
python -m pytest -q
ruff check .
```

Точный исходный запуск: Python 3.14.4, зависимости в `requirements-lock-py314.txt`, SHA-256 данных в `reports/summary.json`. Сырые данные и модели остаются локально. Команда `forecast` создаёт прогноз на следующий день после последней записи, то есть для исходного набора на 01.10.2022.

Путь до рабочего применения: [план ML-команды](ml_team/delivery_plan.md). Измеренная польза на другой пекарне, новая основная модель и автоматическое управление выпуском пока не подтверждены.
