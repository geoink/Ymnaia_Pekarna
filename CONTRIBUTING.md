# Работа над «Умной пекарней»

Начните с [постановки ML-команде](docs/ml_team/brief.md) и [бэклога](docs/ml_team/backlog.md). В задачах указаны зависимости, результаты и критерии приёмки. Роли в карточках — предложения; конкретные исполнители назначаются командой.

## Локальный запуск

```bash
git clone https://github.com/geoink/Ymnaia_Pekarna.git
cd Ymnaia_Pekarna
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'
python -m pytest -q
ruff check .
```

Для воспроизведения исследования выполните `bakery download`, `bakery run` и `bakery research`. Для чтения выполненного ноутбука запуск не требуется. Его зависимости устанавливаются через `python -m pip install -e '.[notebook]'`.

## Как сдавать изменение

Создайте отдельную ветку, свяжите PR с задачей и приложите свидетельства выполнения её критериев. Для эксперимента сохраните версию данных, конфигурацию, временные окна и все сравниваемые варианты. Выбор новой модели по уже изученному тесту требует новой независимой оценки.

Сырые данные, локальные модели и построчные прогнозы остаются локально. Сводные таблицы и графики допустимы с указанием источника; условия исходного набора описаны в [DATA_LICENSE.md](DATA_LICENSE.md).

`MANIFEST.sha256` фиксирует файлы подготовленной поставки. После собственных изменений используйте обычные `git add` / `git commit`; для нового архива пересчитайте manifest. Скрипт первой публикации добавляет только перечисленные в нём файлы.

Порядок ревью и Definition of Done: [план поставки](docs/ml_team/delivery_plan.md).
